# Third-party software

## Slick 1.8.1

- Project: <https://github.com/kenwheeler/slick>
- Files: `assets/vendor/slick/slick.css`, `slick.min.js`
- License: MIT; see `assets/vendor/slick/LICENSE`

## Font Awesome Free 7.3.1

- Project: <https://fontawesome.com/>
- Files: SVG sprites in `assets/vendor/fontawesome/sprites/`
- `assets/vendor/fontawesome/icons.json` is a generated label/style index derived from the official Free icon metadata.
- Licenses: CC BY 4.0 for icons, SIL OFL 1.1 for fonts, and MIT for code; see `assets/vendor/fontawesome/LICENSE.txt`

Both libraries are served locally by the plugin. No runtime CDN request is made.
